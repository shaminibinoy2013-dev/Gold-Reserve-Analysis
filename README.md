Gold Reserve Analysis

Project Overview
  This project analyzes gold reserve data using Python and Power BI.
Tools Used
  Python (Pandas, Matplotlib)
  Power BI

Dataset
  Contains information about gold reserves, including:
  Date
  Location
  Gold quantity (Troy Ounces)
  Book Value

Key Analysis
  Time trend of gold reserves
  Location-wise distribution
  Value analysis

Dashboard
  Interactive dashboard created using Power BI.

Conclusion
  Gold reserves remain stable over time with concentration in specific facilities.
